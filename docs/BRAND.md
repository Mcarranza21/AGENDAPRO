# Brand Brief - AgendaPro

## Esencia

AgendaPro transforma agendas complejas en planes claros, coordinados y fáciles de ejecutar. La marca transmite orden, confianza y agilidad con una apariencia profesional, acogedora y sin ruido visual.

**Promesa:** Cada actividad, persona y horario en su lugar.

## Identidad visual vigente

| Rol | Valor | Uso |
|---|---|---|
| Primario | `#16324F` | Marca, títulos y texto principal |
| Acento | `#087E8B` | Acciones, enlaces, horas y estados activos |
| Fondo | `#F7F9FC` | Fondo general |
| Superficie | `#FFFFFF` | Tarjetas y formularios |
| Texto secundario | `#64748B` | Descripciones y metadatos |
| Borde | `#DCE5EE` | Divisores y controles |

## Tipografía

- **Montserrat:** títulos y marca.
- **Inter:** cuerpo, botones, formularios y metadatos.
- Ambas se cargan desde Google Fonts y conservan alternativas seguras del sistema.

## Componentes y recursos

- Bootstrap 5.3.8 para estructura y componentes.
- Bootstrap Icons para iconografía funcional.
- `assets/agenda-dashboard.svg` como ilustración local del producto.
- `assets/favicon.svg` como favicon local.
- Tarjetas blancas con bordes suaves, radios amplios y sombras discretas.

## Tono de voz

Profesional, acogedor y eficiente. Los mensajes deben explicar qué ocurrió y qué puede hacer el usuario, con español claro y directo. Evitar tecnicismos, exageraciones y una apariencia corporativa rígida.

## Stack vigente

HTML, CSS y JavaScript simples; Bootstrap cargado desde CDN; archivo JSON local para lectura y Supabase para la única escritura requerida. Sin framework, npm ni proceso de compilación.
