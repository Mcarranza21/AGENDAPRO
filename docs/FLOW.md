# AgendaPro — Flujo de Navegación

| | Inicio (home) | Detalle del evento |
|---|---|---|
| **Propósito** | Ser el punto de entrada para crear un evento o continuar trabajando con uno existente. | Mostrar toda la información de un evento y permitir organizar las actividades que forman parte de su agenda. |
| **Información mostrada** | Nombre de los eventos existentes, fecha, estado y opción para crear un nuevo evento. | Nombre del evento, fecha, horario general y listado de actividades con hora y responsable. |
| **Acciones** | Crear un nuevo evento. Abrir un evento existente para ver y continuar su agenda. | Revisar las actividades del evento, agregar una nueva actividad y volver a la lista de eventos. |
| **Navegación** | Es la primera pantalla al abrir AgendaPro. Al seleccionar un evento se abre Detalle del evento. | Se accede al seleccionar un evento desde Inicio. La opción “Volver a eventos” regresa a Inicio. |
| **Estado vacío / error** | “Todavía no tienes eventos. Crea tu primer evento para comenzar.” | “Este evento todavía no tiene actividades. Agrega la primera actividad para comenzar a organizar la agenda.” |
